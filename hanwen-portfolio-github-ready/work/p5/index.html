Overview

Participate in data analysis regarding food security, population density and the implementation of macro policies.

Qualitative and quantitative analyses were conducted using the ArcGIS database software of the University of Toronto.

I looked at food access, where people live and how larger policies are put into practice. I used ArcGIS to study maps and data.
